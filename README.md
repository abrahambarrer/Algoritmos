
# Sistema de trading

Aplicación de consola en Python para administrar transacciones de acciones y buscar registros por timestamp. Genera 300 transacciones aleatorias, ordenadas o en orden inverso; permite agregar y mostrar transacciones, ordenarlas con Bubble Sort optimizado, Selection Sort o Insertion Sort, y comparar el tiempo de ejecución de cada método. También incluye búsqueda binaria por timestamp.

Ejecuta el programa con:

```shell
python main.py
```
